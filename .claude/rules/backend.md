# Backend conventions

- Project managed by `uv` (`backend/pyproject.toml`, `requires-python = ">=3.12"`). Pin major versions; dev extras: pytest, respx, ruff, mypy, freezegun, httpx.
- `app/__init__.py` exposes `__version__`.
- All DB access through SQLAlchemy ORM sessions from `app.db.SessionLocal`; FastAPI dependency `get_db` yields and closes. Services take a `Session` argument, never open their own except scheduler job entrypoints (which open one per job run).
- SQLite engine: `connect_args={"check_same_thread": False}`, `PRAGMA journal_mode=WAL`, `PRAGMA foreign_keys=ON`, `PRAGMA busy_timeout=5000` via `event.listens_for(engine, "connect")`.
- Migrations: Alembic, one initial revision generated by hand (not autogenerate at runtime). `app.db.run_migrations()` called in lifespan before anything else. Tests use `run_migrations()` on a tmp file DB too (so the migration is tested).
- Datetimes: timezone-aware UTC everywhere (`datetime.now(timezone.utc)`); store as naive UTC in SQLite via a `TypeDecorator` or convert at boundaries consistently. Serialize with `Z`.
- Pydantic v2 `BaseModel` schemas in `app/schemas.py`, `model_config = ConfigDict(from_attributes=True)` where mapping from ORM.
- Errors: raise `HTTPException` in routers only; services raise domain exceptions (`PathError`, `FeedFetchError`, `QbitError(transient: bool)`, `SsrfError`).
- httpx: explicit timeouts always. Feed fetch: `timeout=feed_fetch_timeout_seconds`, `User-Agent: feedcatch/<version>`. Stream body and abort beyond 10 MiB.
- feedparser: pass bytes; `feedparser.parse(data, response_headers={'content-type': ...})`. Check `bozo` but tolerate recoverable bozo if entries exist. Treat XML with DOCTYPE/entities as invalid (reject `<!DOCTYPE` and `<!ENTITY` before parsing) to avoid entity expansion.
- Logging: structlog JSON to stdout; level from `APP_LOG_LEVEL`. Include `event`, `feed_id`, `entry_id`, `download_id` keys where relevant.
- Scheduler: `BackgroundScheduler(timezone=utc, job_defaults={"coalesce": True, "max_instances": 1, "misfire_grace_time": 60})`. Job ids: `feed:{id}`, `retry`, `qbit_status`, `retention`. `scheduler.sync_feed_jobs(db)` re-reads feeds and adds/updates/removes jobs; routers call it after feed changes.
- Static SPA: mount `StaticFiles` at `/assets` with `Cache-Control: public, max-age=31536000, immutable`; `index.html` served for any non-API GET with `Cache-Control: no-cache`. `GZipMiddleware(minimum_size=1000)`.
- Security headers middleware: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: same-origin`.
- Ruff config: `line-length = 120`, select `E,F,I,B,UP,SIM`. mypy: `python_version = "3.12"`, `ignore_missing_imports = true`, `check_untyped_defs = true`.
- Tests: `tests/conftest.py` provides `db` (tmp sqlite via migrations), `client` (TestClient with auth disabled via settings override), `respx_mock`. Fixture RSS files under `tests/fixtures/`.
  Must include tests listed in `.claude/rules/verification.md`.
- No print(); no bare except; no global mutable state except the scheduler singleton and feed locks dict.
